 🗄️ Ultimate MySQL Query Hub: Basics to Intermediate

> A structured collection of MySQL problem-solving exercises containing practical questions, detailed explanations, and ready-to-run query examples covering every fundamental to intermediate database topic.

📌 About the Repository
This repository serves as a **complete learning guide** for mastering MySQL. It transitions smoothly from basic data retrieval to intermediate data transformations. Every single topic is structured as follows:
* The Problem Statement: Real-world scenarios and specific questions.
* The MySQL Query: Optimized, clean, and well-formatted SQL code.
* The Practical Example: Hands-on context to understand *why* and *how* the query works.

🗺️ Topics Covered

🟥 Basics (Foundational Concepts)
* Data Retrieval: Writing `SELECT` statements to query specific columns or entire tables.
* Data Filtering: Restricting rows using `WHERE` clauses, comparison operators, and logic (`AND`, `OR`, `NOT`).
* Pattern Matching: Filtering text using `LIKE`, `IN`, `BETWEEN`, and wildcards.
* Data Ordering: Sorting query outputs cleanly with `ORDER BY`.
* Limit & Distinct: Restricting result counts using `LIMIT` and fetching unique rows via `DISTINCT`.

🟨 Intermediate (Data Analysis & Relationships)
* Aggregate Functions: Performing calculations using `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
* Data Grouping: Structuring datasets with `GROUP BY` and filtering groups using `HAVING`.
* Multi-Table Joins: Connecting relational tables using `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `FULL JOIN`.
* Subqueries: Writing nested queries within `WHERE`, `FROM`, or `SELECT` clauses.
* Built-in Functions: Working with core String, Numeric, and Date/Time manipulation tools.

🚀 How to Use This Repository
1. Browse by Topic: Explore the folders organized sequentially from basic to intermediate difficulty.
2. Read the Question: Every folder/file starts with a practical question or data challenge.
3. Run the Code: Copy the provided query examples directly into your local MySQL Workbench or SQL editor.
